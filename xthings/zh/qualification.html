同时验证经济性与技术匹配

不是每个联网空间机会都值得投入企业级 BD 时间。

先用 BANT 快速确认商业真实性，再用 MEDDPICC 管理复杂交易。IQ 模型用于排序资源投入，但权重应持续由真实赢单/输单数据校准。

三类核心 ICP 打法

伙伴杠杆、物业规模与高风险设施。

现有研究指向三类值得优先验证的打法。在确定长期 ICP 层级前，我会用 Xthings 的真实毛利、软件挂载率、支持成本和成交历史进行验证。

ICP A · 渠道

系统集成商 + MSP

服务商业客户的安防安装商、弱电承包商和 IT 服务商。

  • 需求：现代云/边缘能力，同时保留实施利润
  • 决策角色：老板、运营 VP、采购、解决方案工程
  • 触发：改造投标、新客户要求、替换旧平台
ICP B · 物业

多户住宅 + 商业物业

负责门禁、入住周转与多站点运营的开发商、运营商与物业团队。

  • 需求：凭证自动化、更少现场访问、集中设备运营
  • 决策角色：资产管理、物业运营、开发、财务
  • 触发：新建、翻新、组合标准化、住户周转
ICP C · 企业

制造业 + 高安防设施

身份、可用性与可审计性要求高的工业、科技及其他设施。

  • 需求：高韧性门禁、生物识别、视频验证、企业身份集成
  • 决策角色：安防、设施、IT、风险
  • 触发：扩建、审计问题、新安防负责人、替换旧平台
按 ICP 预估交易规模

用少量高价值成交支撑 200 万美元配额。

以下为面试研究中的工作假设区间，并非 Xthings 官方 ASP。入职首月应验证硬件毛利、云挂载、服务收入与收入计入规则。

渠道 · 安防系统集成商$100K-$250K

面向企业、工业和多站点项目的商业弱电/安防伙伴。

打法：Partner IQ → 高管/老板发现会 → 技术工作坊 → 1 个报备灯塔项目 → 复制联合销售。
物业 · 多户住宅 / 开发商$150K-$500K+

100-500+ 户项目，组合智能锁、公共区域门禁、视频、集成与经常性云收入。

打法：许可/开发信号 → 运营 VP + 设计团队 → 样板单元试点 → 组合标准化。
企业 · 制造业约 $125K-$300K

以研究中的 $183K 工厂模型为锚：边缘网关、生物识别门禁、视频/身份集成和云。

打法：扩建/安防触发 → 安防 + 设施 + IT → 受控试点 → 多站点部署。
MSP / IT 伙伴$30K-$90K

首单规模较小，围绕身份、办公门禁和客户部署，通过持续引荐放大价值。

打法：Entra / Okta / HR 工作流 → 集成证明 → 联合客户试点 → 纳入托管服务组合。
A&E / 安防顾问影响 $200K+ 项目

其价值并非直接配额，而是在项目进入投标前影响规格设计与 RFP。

打法：教育 → 参考架构 → 规格支持 → 交给认可集成商。
商业地产 / 租户代表网络影响 $50K+ 项目

用于新办公室、仓库和租户改造的次优先级线索渠道。

打法：共享触发信号 → 办公安防清单 → 合格引荐给直销或渠道负责人。
规划依据：面试研究估算。在 Xthings 内部 ASP、毛利与云挂载数据替换前，这些区间明确作为假设展示。
BANT → MEDDPICC

先快速筛选，再用企业级纪律推进。

BANT 判断是否存在可信商机；MEDDPICC 判断组织是否真正能购买、实施并在内部支持该决策。

BANT预算 · 权限 · 需求 · 时间

如果某项未知，明确需要什么证据；如果四项都弱，不要强行推进企业销售。

MEDDPICC · 价值指标 · 痛点 · 内部拥护者

定义运营/财务结果，以及真正有动力推动交易的人。

MEDDPICC · 决策经济买家 · 决策标准 · 决策流程

映射谁批准、需要哪些技术与商业证明，以及先后顺序。

MEDDPICC · 成交合同流程 · 竞争

安审、采购、MSA、隐私、伙伴协议，以及客户真正的替代方案。
